Privacy Policy

docchan-replies is used only by the owner of the connected YouTube channel and Instagram account.

  • Data accessed: public comments on the owner's own videos (comment text and comment ID), via the YouTube Data API and Instagram API.
  • Use: to decide whether to reply and to post a short reply on the owner's behalf.
  • Storage: access tokens are stored as encrypted GitHub Actions secrets. Comment text is not sold, shared or used for advertising.
  • Deletion: revoke access anytime at https://myaccount.google.com/permissions.

docchan-replies' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
